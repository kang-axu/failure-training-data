# Data and Case Policy

Before any case, example, dataset, or related artifact enters this public repository, answer all four questions:

1. Is it a publicly verifiable historical fact?
2. Does it contain real internal project data?
3. Does it expose internal judgment or correction logic?
4. Would external access materially shorten the path to copying our capability?

If the answer to question 2, 3, or 4 is **yes**, it must not be directly published by default.

The permitted alternatives are:

- sanitize
- synthesize
- reduce to a higher-level teaching form
- move it to private storage

This policy applies to text, prompts, examples, datasets, screenshots, attachments, code, configuration, and Git history.
